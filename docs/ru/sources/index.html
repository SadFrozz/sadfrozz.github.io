Область проверки

  • Изучены README, ключевые исходники, требования сборки, опубликованные релизы и все ветки, возвращённые GitHub API. Сопоставлены деревья main и последних тегов.
  • Media Import: во время финальной проверки опубликован v1.3.0. Его тег и main имеют одинаковое дерево исходников. dLab.Series, WebView и Web Prompter также имеют одинаковые деревья main и соответствующих релизных тегов. У MCU Display различается только ссылка в README.
  • Ath10k: изучены main и native-sequoia-development, включая отдельную карту состояния разработки. Отсутствие релизов не заменено обещанием стабильной сборки.
  • Под «проверено» понимается проверка документации по коду и публичным источникам. Новых проверок аудио, REAPER, оборудования или сборок 1.3.0 не выполнялось.
  • Портал содержит только специально подготовленный текст и сведения из публичных репозиториев. Личные файлы, рабочие проекты, пароли, ключи, сетевые дампы и настройки в него не копировались.
