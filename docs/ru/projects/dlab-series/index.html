dLab.Series

Плагины серии dLab вдохновлены channel-strip устройствами от dbx, говорят неотличимо от оригинала.

Windows x64macOS 11+VST3 · VST2 · AU
Загрузки ↓Исходники ↗Ченджлог ↗
v1.0

Два плагина

  • dLab 286: входное усиление, low-cut, компрессор Drive/Density, де-эссер, LF/HF Detail, экспандер/гейт и выходной уровень. Режимы Project One и 286S.
  • dLab 376: Warm/Bright/Muted, EQ, компрессор OverEasy с FAST/SLOW, де-эссер и выходной уровень. Оверсемплинг Off/2x/4x, по умолчанию Off.

Требования

  • Windows 64-bit: VST3 и VST2. macOS 11+: Universal Intel/Apple Silicon, VST3, AU и VST2. Нужна DAW или другой хост нужного формата.
  • Для OBS выбирайте VST2: 286 и 376 устанавливаются двумя отдельными плагинами. Самостоятельного приложения нет.

Установка

  1. Закройте DAW, OBS и другие приложения, использующие плагины. Скачайте установщик Windows x64 или macOS Universal из v1.0.
  2. В Windows выберите форматы и папки VST3/VST2. В macOS форматы выбираются через Customize.
  3. Откройте хост и обновите список плагинов. Найдите dLab 286 и dLab 376.
  4. Windows-установщик предлагает удалить старые беты Channel286/376/386/676 из выбранной папки VST3. Не держите старые 286/376 рядом с новыми: хост может считать их одним плагином. Сохраните копию нужной старой версии перед заменой.

Использование

  • Добавьте dLab 286 или dLab 376 на моно- или стереодорожку. Настройте вход, обработку и выход, сравнивая результат при сопоставимой громкости.
  • В 286 выбирайте режим Project One или 286S, затем Drive/Density, де-эссер, Detail и гейт. Встроенные подсказки подсвечивают диапазоны ручек, но не меняют ваши значения.
  • В 376 выберите Warm, Bright или Muted и при необходимости включите оверсемплинг. Это варианты тембра, а не модели конкретных марок ламп. Финальный дизеринг и шумоформирование выполняйте в DAW.

Ограничения

  • Установщик macOS без подписи Developer ID и нотарификации Apple. Плагины подписаны ad hoc. В Universal-сборке есть версии для Intel и Apple Silicon.
  • dLab независимо моделирует звуковую обработку устройств dbx. Фантомное питание +48 В, AES/SPDIF и внешний word clock отсутствуют.
  • Готовые сборки доступны для Windows и macOS.

Если хост не видит плагин

  • Проверьте установленный формат и путь сканирования хоста. Для OBS нужен VST2. После удаления старых бет повторите сканирование.
  • В Issue укажите ОС, хост и версию, формат плагина и шаги воспроизведения.

Сборка

  • Git с submodules, CMake 3.22+, Python 3. Windows: Visual Studio 2022 C++/Windows SDK, для установщика NSIS 3.10+. macOS: Xcode Command Line Tools. JUCE 8.0.12 зафиксирован как submodule; исходный ZIP с GitHub его не содержит.
  • Windows использует preset windows-x64; macOS — macos-universal. Сборка сама не устанавливает плагины. Полная упаковка описана в docs/BUILDING.md.
git clone --recurse-submodules https://github.com/SadFrozz/dLab.Series.git
cd dLab.Series
cmake --preset windows-x64
cmake --build --preset windows-x64
ctest --preset windows-x64
