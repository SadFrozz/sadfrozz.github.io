Ath10k-airport

Экспериментальный Wi-Fi-драйвер Qualcomm Atheros для macOS с управлением через системное меню.

macOS SequoiaOpenCoreQCA9377
Загрузки ↓Исходники ↗Ченджлог ↗
Без релиза

Статус разработки

  • Нативный kext для OpenCore: обнаружение сетей, подключение и IPv4/IPv6 без companion-приложения, login agent, OCLP и патчей системного тома.
  • Готовых релизных пакетов нет. Основная ветка — main. Экспериментальная поддержка дополнительных способов подключения развивается в native-sequoia-development.

Требования и подтверждённая область

  • Связка с результатами аппаратных испытаний: QCA9377 (PCI 168c:0042, subsystem 1a3b:2b51), x86_64, macOS Sequoia 15.6.1 (24G90). Другие карты и версии macOS могут потребовать отдельной адаптации.
  • OpenCore и проверенная конфигурация загрузки. Нужна сохранённая рабочая EFI и альтернативный доступ к сети. macOS 11–26 — цель разработки, а не готовая матрица совместимости.

Сборка и установка

  1. Готового релизного пакета сейчас нет. Сначала выберите зафиксированный исходный коммит для своей задачи и прочитайте руководство совместимости.
  2. Для сборки на macOS нужны Apple command-line toolchain, Python 3 и pinned submodules. Обычная сборка main приведена ниже; результат — build/native/out/Ath10kMac.kext.
  3. Сохраните рабочую EFI. Скопируйте функциональный Ath10kMac.kext в EFI/OC/Kexts и добавьте/обновите включённую запись Kernel → Add в config.plist.
  4. Проверьте конфигурацию OpenCore и соответствие сборки ОС/оборудованию до перезагрузки. После загрузки используйте стандартное меню Wi-Fi и сверяйте реально загруженную сборку.
  5. Не устанавливайте controller-only DIAGNOSTIC_STAGE=3 или криптографический диагностический вариант как полноценный Wi-Fi-драйвер.
git clone --recurse-submodules https://github.com/SadFrozz/Ath10k-airport.git
cd Ath10k-airport
make -j2 kext
# Local regression suite:
make test-development

Использование и ветки

  • Main: нативное сканирование, WPA2-Personal и экспериментальный opt-in WPA3-SAE/PMF. SAE выключен в стандартной сборке. Для него README задаёт NATIVE=1 NATIVE_SAE_EXPERIMENTAL=1 NATIVE_PMF_PROBE=0 DIAGNOSTIC_STAGE=0.
  • В native-sequoia-development добавлены способы подключения OWE, WPA1, WEP и Enterprise/EAP. На QCA9377 удалось подключиться по OWE, OWE Transition, WPA1-CCMP, WPA2 и WPA3. Enterprise остаётся нестабильным, а работа в режиме только TKIP не подтверждена.
  • Контракты, флаги сборки и карта состояния native-sequoia-development находятся в документации этой ветки на GitHub.

Ограничения

  • При длительной работе возможны задержки, ошибки передачи и разрывы соединения.
  • WPA3 и PMF экспериментальны. Совместимость group BIP и смены ключей по запросу точки доступа ещё не подтверждена.
  • Роуминг по запросу системы реализован. Переход между физическими точками доступа и работа после сна остаются экспериментальными.
  • AWDL, AirDrop, FT и SAE-PK не реализованы. Enterprise/EAP доступен только как эксперимент в ветке разработки.
  • Корневая лицензия не покрывает автоматически firmware и все зависимости; в публичном license-audit зафиксированы нерешённые вопросы совместимости лицензий.

Диагностика

  • В Issue указывайте build macOS, PCI/subsystem IDs, версию/UUID реально загруженного драйвера и шаги воспроизведения. Перед отправкой очистите диагностику от SSID, MAC, паролей, ключей и личных путей.
  • Если кext не загрузился, проверьте OpenCore Kernel → Add, зависимости и подпись выбранного артефакта. При проблемах вернитесь к сохранённой рабочей EFI.

Лицензии

  • Смотрите LICENSE, firmware/README.md, dependency guide и docs/guides/license-audit.md. Сохраняйте уведомления сторонних авторов при распространении.
