Интерактивный текстовый монитор

Интерактивная монтажка (телесуфлёр) для работы с озвучкой. Поддерживается работа по сети с мобильных устройств.

REAPERWindows · macOSLAN

v1.5.1

Текст рядом с таймлайном

  • Телесуфлёр и интерактивная монтажка работают во встроенном WebView или браузере в локальной сети. Lua-backend получает текст из заметок медиаайтемов P_NOTES выбранной дорожки и передаёт его веб-интерфейсу.
  • В интерфейсе есть роли, фильтры, сегментация, статистика и автопрокрутка.

Требования

  • REAPER с Lua ReaScript, подготовленные текстовые айтемы и настроенный HTTP-интерфейс Control/OSC/web.
  • Для встроенного режима: reaper_webview, а в Windows ещё WebView2 Runtime. Для внешнего браузера расширение WebView не требуется. Инсталлеры опубликованы для Windows и macOS.

Установка

  1. Скачайте .exe для Windows или .command для macOS из v1.5.1. Сохраните резервную копию изменяемых настроек REAPER перед установкой.
  2. Запустите инсталлер и подтвердите папку ресурсов активной установки REAPER. Он копирует Scripts, reaper_www_root и комплектный плагин при наличии.
  3. Разрешите добавление HTTP web-интерфейса либо настройте его вручную в Preferences → Control/OSC/web, указав prompter.html.
  4. Перезапустите REAPER. В Action List должны появиться Custom: Web Prompter Backend и Custom: Web Prompter Launch.
  5. Для ручной установки скопируйте Scripts и reaper_www_root в папку ресурсов, добавьте backend и launch Lua-скрипты в Action List. UserPlugins нужен только встроенному режиму. Точные записи reaper-kb.ini есть в README.

Первый запуск

  • Подготовьте дорожку с текстом в заметках медиаайтемов. Времена айтемов задают начало и конец реплик. Прямое чтение SWS Notes и текста маркеров не заменяет эти данные.
  • Запустите Web Prompter Backend, затем Web Prompter Launch. Выберите дорожку с текстом. Для планшета откройте HTTP-адрес REAPER из Control/OSC/web в той же локальной сети.
  • Настройте роли и актёров, solo/mute или затемнение, UI Scale и автопрокрутку «строка»/«страница». Цвет актёра имеет приоритет; цвета проекта можно игнорировать.
  • Сегменты определяются по маркерам/видео или вручную. Если видна только часть текста, проверьте сегментацию и режим «Весь проект». Jump по клику учитывает пре-ролл и запреты при воспроизведении/записи.

Ограничения и данные

  • Нет редактирования исходного текста прямо в мониторе и собственного импорта SRT/ASS. Подготовьте текст в REAPER; Media Import — отдельное расширение, которое может создать текстовые айтемы.
  • Текст сохраняется в reaper_www_root/subtitles.json, глобальные настройки — в settings.json. Карта ролей хранится рядом с сохранённым проектом в <project>-roles.json.
  • REAPER запускает HTTP-интерфейс на компьютере с проектом. Открывайте его только в доверенной локальной сети.
  • Встроенный режим Windows требует WebView2 Runtime, совместимого с вашей версией Windows.

Если монитор пустой

  • Проверьте backend, выбранную дорожку и непустые P_NOTES. Затем проверьте HTTP csurf с prompter.html и выбранный порт.
  • Сохраните проект при проблеме с его именем; перезапустите Launch при ошибках отображения. Если клик не перемещает курсор, проверьте Jump, пре-ролл и защиту транспорта.

Исходники и обновление

  • Исходники состоят из Lua-скриптов, статического веб-интерфейса и Python-инсталлера. Workflow main.yaml собирает публикационные инсталлеры.
  • При обновлении сохраните настройки и проектные карты ролей, затем замените Scripts, reaper_www_root и при необходимости UserPlugins либо используйте инсталлер. Перезапустите REAPER.

Лицензия
