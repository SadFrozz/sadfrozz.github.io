REAPER WebView

Браузер внутри REAPER: докируемые окна, отдельные вкладки и управление из ReaScript.

Встроенный браузер

  • Расширение использует WebView2 в Windows и WKWebView в macOS. Поддерживает несколько окон, поиск по странице, контекстное меню, сохранение положения и проброс сочетаний клавиш в REAPER.
  • Последняя публикация — v0.2.0 от 11 сентября 2026 года, помечена Pre-release. Main совпадает с тегом на момент проверки.

Требования

  • REAPER на Windows x64 или macOS с подходящей Universal-библиотекой. Windows требует Microsoft Edge WebView2 Runtime; SDK для сборки не заменяет установленный Runtime.
  • Доступ в сеть нужен для сетевых страниц. Встроенный WKWebView использует системный движок macOS. В README не установлен точный минимальный номер версии REAPER — здесь он не придуман.

Установка

  1. Откройте релиз v0.2.0 и скачайте архив своей платформы. Ссылки /releases/latest могут пропускать предварительные версии; используйте точную ссылку ниже.
  2. Через Options → Show REAPER resource path откройте папку ресурсов и закройте REAPER.
  3. Распакуйте содержимое архива в UserPlugins: reaper_webview.dll в Windows или reaper_webview.dylib в macOS. Если архив содержит WebView2Loader.dll, сохраните его рядом с расширением.
  4. Перезапустите REAPER. Для обычной работы используйте Release-библиотеку; debug-вариант предназначен для диагностики.

Использование и API

  • Создайте Lua ReaScript, выполните пример ниже. Он открывает отдельный именованный браузер внутри Docker.
  • InstanceId: wv_default по умолчанию, random создаёт последовательные wv_N, своё имя должно начинаться с wv_. Иное имя приводится к wv_default.
  • ShowPanel принимает hide, docker или always. SetTitle задаёт пользовательский заголовок; BasicCtxMenu включает минимальное меню. URL "0" позволяет применить опции без смены страницы.
  • В Preferences → Plug-ins → WebView настраиваются домашняя страница, проброс хоткеев и восстановление окон. Ctrl+F/Cmd+F открывает поиск.
reaper.WEBVIEW_Navigate("https://www.reaper.fm/",
  '{"InstanceId":"wv_reference","SetTitle":"Reference","ShowPanel":"docker"}')

Ограничения

  • Это предварительный релиз. Linux не поддерживается текущей сборкой.
  • Маршрутизация звука браузера в аудиограф REAPER/ReaRoute находится в планах и не реализована как готовая функция.
  • В macOS подсветка поиска ограничена 5000 совпадениями с резервным подсчётом. Поведение конкретных сайтов зависит от системного веб-движка.
  • Поддержку устаревших Windows нельзя выводить из старых FAQ других проектов: проверьте совместимость доступного WebView2 Runtime с вашей ОС.

Если окно не открывается

  • Убедитесь, что расширение загружено: функция reaper.WEBVIEW_Navigate должна существовать. Проверьте активную папку ресурсов, архитектуру и Runtime Windows.
  • Для нескольких окон используйте разные wv_* или random. Для отчёта приложите ОС, версию REAPER, URL воспроизведения без приватных параметров и минимальный Lua-пример.

Сборка

  • Клонируйте с --recurse-submodules. Нужны CMake 3.20+, C++ toolchain, REAPER SDK, WDL и в Windows WIL. WebView2 SDK загружается CMake из NuGet.
  • Таргеты: reaper_webview и reaper_webview_debug. В macOS требуется Xcode toolchain. Полные команды и структура приведены в README.
cmake -S . -B build
cmake --build build --config Release --target reaper_webview
