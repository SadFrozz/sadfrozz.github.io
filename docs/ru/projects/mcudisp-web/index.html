MCU Display Web

Веб-реализация дисплея Mackie Control Universal. Работает с совместимыми устройствами, must-have для безэкранных контроллеров.

Python 3MIDI + OSCLAN

v1.2Сверено 24.11.2026

Внешний дисплей по сети

  • Python-сервер принимает текст по MIDI SysEx, таймкод и транспорт по OSC, затем передаёт их браузеру через Socket.IO. На экране две строки по 56 символов: восемь ячеек по семь символов.
  • Последний релиз — v1.2 от 30 августа 2025 года, без готовых бинарных файлов. Используется исходный код. Main отличается от тега одной ссылкой в README; серверный код совпадает.

Требования

  • Python 3 и зависимости requirements.txt: mido, python-rtmidi, Flask, Flask-SocketIO, python-osc, eventlet. Версии зависимостей не зафиксированы.
  • REAPER, MIDI-контроллер или совместимый MIDI-маршрут с нужными SysEx, браузер и локальная сеть. В README рекомендован DrivenByMoss4Reaper для MCU.

Установка

  1. Клонируйте репозиторий и выберите тег v1.2. Создайте отдельное окружение Python, затем установите requirements.txt.
  2. В REAPER → Preferences → Control/OSC/web добавьте MCU или DrivenByMoss и настройте MIDI вход/выход контроллера.
  3. Добавьте OSC (Open Sound Control): Configure device IP + port, Host 127.0.0.1, Send to port 9000. В используемом ReaperOSC-профиле должны быть FRAMES s/frames/str, PLAY t/play и RECORD t/record.
  4. Выполните python list_ports.py. В server.py задайте SEARCH_TERM как уникальную часть имени нужного MIDI input; поиск чувствителен к регистру.
  5. Запустите python server.py из папки проекта. Откройте на другом устройстве http://<LAN-IP-компьютера>:5000/.
git clone https://github.com/SadFrozz/mcudisp-web.git
cd mcudisp-web
git checkout v1.2
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python list_ports.py
# Set SEARCH_TERM in server.py before starting:
python server.py

Использование

  • Включите MCU-режим контроллера и убедитесь, что текст дисплея попадает во входной MIDI-порт сервера. OSC передаёт таймкод и статусы отдельно от MIDI.
  • Для подписей F1–F8 создайте func.txt в рабочей папке: одна подпись на строку, читаются первые восемь строк. Без читаемого файла блок скрыт. Перезапустите сервер после изменения.
  • Интерфейс масштабируется под экран. PLAY/STOP и зелёная/красная схема показывают состояние транспорта и записи.

Ограничения, проверенные по коду

  • Хотя README описывает MCU-совместимые устройства в целом, server.py фильтрует конкретный Behringer SysEx-префикс (0, 32, 50, 0, 20, 120). Другой MCU-контроллер не становится совместимым только от смены SEARCH_TERM; может понадобиться изменение парсера.
  • OSC слушает только 127.0.0.1:9000, веб-сервер — 0.0.0.0:5000. MIDI-порт ищется по подстроке и выбирается первый подходящий. Если порт занят DAW, доступ зависит от драйвера и маршрутизации.
  • Нет встроенных учётных записей, TLS и настройки для публичного сервера. Код использует allow_unsafe_werkzeug=True. Это локальный дисплей для доверенной сети, а не сервис для публикации в интернете.
  • Нет опубликованной матрицы минимальных версий Python/ОС или подтверждения всех контроллеров. Нефиксированные зависимости могут требовать подбора совместимых версий. Физическое MIDI/OSC-оборудование в рамках подготовки портала не проверялось.

Если экран пустой

  • Нет названий: проверьте входы через list_ports.py, SEARCH_TERM, MIDI-маршрут и SysEx-префикс. Нет таймкода: проверьте OSC 9000 и профиль ReaperOSC.
  • Страница недоступна с планшета: используйте LAN-адрес компьютера, ту же сеть и доступ к TCP 5000 в межсетевом экране. Не используйте 127.0.0.1 на планшете для доступа к компьютеру.

Исходники

  • Отдельной компиляции нет. server.py — сервер, list_ports.py — список входов, templates/index.html — интерфейс. Запускать нужно локально: GitHub Pages не исполняет Python и не подключает MIDI.
