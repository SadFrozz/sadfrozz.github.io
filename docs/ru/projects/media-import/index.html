Reaper Media Import

Расширенная поддержка кодеков, работа с HDR-видео без необходимости конвертации, а также импорт субтитров на дорожку как текст.

v1.3.0Сверено 24.11.2026

Что делает расширение

  • Нативное расширение дополняет импорт REAPER: raw Dolby/DTS/MLP, потоковое чтение TrueHD+AC3, ASS/SSA/SRT/WebVTT и выбор звука в многодорожечных MKV/MP4. Аудио и видео читаются из исходного контейнера.
  • Опубликованный релиз: v1.3.0 от 24 ноября 2026 года. В нём добавлены аппаратный HDR-тонмаппинг и страница настроек Media Import. На момент финальной проверки main совпадает с тегом v1.3.0.

Требования

  • REAPER 7.66+; для FFmpeg 9.x нужен REAPER 7.80+. Windows x64 или macOS 11+ (Universal 2: Intel и Apple Silicon).
  • Полная shared-сборка FFmpeg 5.x–9.x: libavcodec/libavformat с major ABI 59–63 и зависимые библиотеки. Обычный исполняемый ffmpeg или статический архив не заменяют shared-библиотеки.

Установка

  1. Скачайте архив v1.3.0 для Windows или macOS по ссылкам ниже. При необходимости сверьте SHA256SUMS.txt из того же релиза.
  2. В REAPER откройте Options → Show REAPER resource path in explorer/finder. Закройте REAPER.
  3. Скопируйте reaper_frzz_media_import.dll (Windows) или reaper_frzz_media_import.dylib (macOS) в UserPlugins внутри папки ресурсов.
  4. Разместите там же shared-библиотеки FFmpeg подходящей архитектуры. В Windows скопируйте DLL из bin полной shared-сборки; в macOS используйте совместимые dylib или ссылки на установленные библиотеки.
  5. В Preferences → Media → Video/Import/Misc поставьте ffmpeg_hw в приоритет видеодекодеров. Перезапустите REAPER. Подробные команды для FFmpeg и macOS quarantine приведены в README выбранного тега.

Использование

  • Перетащите поддерживаемое raw-аудио в проект или вставьте его обычной командой импорта. Для .thd+ac3 читается TrueHD-поток; промежуточный файл не создаётся.
  • Вставьте MKV/MP4 с несколькими аудиопотоками и выберите дорожку по языку, названию, кодеку и каналам. Пункт Item → Audio track или контекстное меню меняет дорожку активного тейка. Выбор сохраняется в проекте; Undo/Redo работают одним шагом.
  • ASS/SSA/SRT/VTT становятся текстовыми айтемами с таймингом относительно позиции импорта. Поддерживаются UTF-8 и UTF-16 LE/BE с BOM. Это можно использовать как подготовку текста для Web Prompter.
  • В Preferences → Plug-ins → Media Import настраиваются выбор дорожек, HDR/Dolby Vision → SDR, исправления HEVC и пропуск кадров при перемотке. Apply действует без перезапуска. Аппаратный HDR доступен на Windows x64 и Intel Mac; кэш Windows хранится в UserPlugins/Shaders.
  • Dolby Vision Profile 5 использует RPU, Profile 7 — базовый слой с RPU, Profile 8.1 — базовый HDR10. Это границы реализации из релизного описания, а не обещание обработки всех вариантов Dolby Vision.

Ограничения

  • Регистрация расширения файла не гарантирует поддержку любого его варианта. AC-4 и редкие DTS-HD/ES/X/UHD без воспроизводимых образцов не заявлены как проверенные. Переименование файла не меняет кодек.
  • Высотные каналы выбранной дорожки не сохраняются: например, 7.1.2 импортируется как 7.1 с основными каналами и LFE. Это не рендер объектов Atmos.
  • Стили, расположение и визуальные слои субтитров не переносятся в оформление текстовых айтемов. SRT ограничен 10 исходными строками на айтем.
  • Нативный выбор дорожек зависит от проверенных точек подключения конкретных сборок REAPER. Новая версия REAPER может требовать отдельной проверки.
  • Для текущего кода опубликованы результаты Windows и Intel Mac; наличие arm64 в сборке не доказывает повторную проверку всех функций на Apple Silicon. HDR на Intel Arc/QSV остаётся экспериментальным и не проверен на реальном Arc.

Если импорт не работает

  • Проверьте папку ресурсов активной установки REAPER: у portable-версии она может отличаться от стандартной. Убедитесь, что архитектуры расширения, REAPER и FFmpeg совпадают.
  • Проверьте наличие именно shared-библиотек и выбранного видеодекодера. Для отчёта укажите версии REAPER, расширения, FFmpeg и воспроизводимый формат; не прикладывайте личные медиа без необходимости.

Сборка из исходников

  • Для воспроизведения релиза используйте тег v1.3.0. Нужны CMake 3.24+, submodules, Visual Studio 2022/Windows SDK или Xcode Command Line Tools.
  • Команды Windows после клонирования с --recurse-submodules приведены ниже. macOS использует presets macos-universal и mac-universal-release. Аппаратный HDR включён по умолчанию на Windows x64 и Intel Mac; флаги FRZZ_ENABLE_WINDOWS_HDR и FRZZ_ENABLE_MACOS_HDR позволяют его отключить. Кривые и обработка RPU адаптированы из libplacebo и компилируются в расширение, шейдеры используют D3D11/OpenGL.
cmake --preset vs2022-x64
cmake --build --preset release
ctest --preset release
