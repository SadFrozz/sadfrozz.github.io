dLab.Series

Two channel strips: dLab 286 and dLab 376. Compression, de-essing and tone shaping in one window.

Windows x64macOS 11+VST3 · VST2 · AU
Downloads ↓Source code ↗
v1.0Reviewed 24 Nov 2026

Two plugins

  • dLab 286: input gain, low-cut, Drive/Density compression, de-essing, LF/HF Detail, expander/gate and output gain. Project One and 286S modes.
  • dLab 376: Warm/Bright/Muted tonal choices, EQ, OverEasy compression with FAST/SLOW, de-essing and output gain. Off/2x/4x oversampling, off by default.
  • Latest release: v1.0, 11 October 2026. Main’s tree matches the v1.0 tag at this snapshot.

Requirements

  • Windows 64-bit: VST3 and VST2. macOS 11+: Universal Intel/Apple Silicon, VST3, AU and VST2. A compatible DAW or plugin host is required.
  • For OBS, use VST2: 286 and 376 install as two separate plugins. There is no standalone application.

Installation

  1. Close your DAW, OBS and other plugin hosts. Download the Windows x64 or macOS Universal installer from v1.0.
  2. On Windows, select formats and VST3/VST2 folders. On macOS, choose formats through Customize.
  3. Reopen your host and rescan. Look for dLab 286 and dLab 376.
  4. The Windows installer offers to remove older Channel286/376/386/676 beta plugins from the chosen VST3 folder. Avoid keeping old 286/376 versions beside the new plugins: the host may identify them as the same plugin. Preserve any old version you need before replacing it.

Usage

  • Insert dLab 286 or dLab 376 on a mono or stereo track. Adjust input, processing and output while comparing at similar listening levels.
  • In 286, choose Project One or 286S, then adjust Drive/Density, de-essing, Detail and gate. Built-in guides highlight suggested knob ranges without changing values.
  • In 376, choose Warm, Bright or Muted and enable oversampling if needed. These are tonal variations, not models of specific tube brands. Apply final dithering and noise shaping in the DAW.

Limitations

  • The macOS installer has no Developer ID signature or Apple notarization; plugin bundles are ad-hoc signed. Universal includes both architectures, but published local checks were performed on Intel Mac.
  • An independent emulation based on operating principles and public information, unaffiliated with dbx/Harman. Physical features such as +48 V, AES/SPDIF and external word clock are not fabricated processing parameters.
  • Automated DSP/host checks do not replace testing in your DAW or OBS. No Linux build is published.

If the host cannot find a plugin

  • Check the installed format and host scan path. OBS needs VST2. Rescan after removing conflicting beta versions.
  • Report OS, host/version, plugin format and reproduction steps in an Issue.

Building

  • Git with submodules, CMake 3.22+, Python 3. Windows: Visual Studio 2022 C++/Windows SDK and NSIS 3.10+ for installers. macOS: Xcode Command Line Tools. JUCE 8.0.12 is pinned as a submodule; GitHub source ZIPs do not include it.
  • Use windows-x64 on Windows and macos-universal on macOS. Building does not install plugins. See docs/BUILDING.md for packaging.
git clone --recurse-submodules https://github.com/SadFrozz/dLab.Series.git
cd dLab.Series
cmake --preset windows-x64
cmake --build --preset windows-x64
ctest --preset windows-x64
