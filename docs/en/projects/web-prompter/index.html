Interactive Text Monitor

An interactive cue sheet and teleprompter for voice-over work. Supports mobile devices over the network.

REAPERWindows · macOSLAN

v1.5.1Reviewed 24 Nov 2026

Text beside your timeline

  • A teleprompter and interactive cue sheet, embedded in WebView or opened in a LAN browser. The Lua backend reads media-item P_NOTES on the selected track and provides data to the web UI.
  • Latest release: v1.5.1, 18 November 2025. Main matches the tag at this snapshot. Includes roles, filters, segmentation, statistics and auto-scrolling.

Requirements

  • REAPER with Lua ReaScript, prepared text items and an HTTP interface under Control/OSC/web.
  • Embedded mode needs reaper_webview and, on Windows, WebView2 Runtime. An external browser does not need the WebView extension. Installers are published for Windows and macOS.

Installation

  1. Download the Windows .exe or macOS .command from v1.5.1. Back up affected REAPER settings before installation.
  2. Run the installer and confirm the active REAPER resource folder. It copies Scripts, reaper_www_root and a bundled plugin when present.
  3. Allow HTTP interface setup or configure it manually under Preferences → Control/OSC/web with prompter.html.
  4. Restart REAPER. Action List should include Custom: Web Prompter Backend and Custom: Web Prompter Launch.
  5. For manual setup, copy Scripts and reaper_www_root into the resource folder and register the backend and launch Lua scripts in Action List. UserPlugins is needed only for embedded mode. See README for exact reaper-kb.ini entries.

First run

  • Prepare a track with text in media-item notes. Item positions and lengths define cue timing. SWS Notes and marker text do not substitute for these data.
  • Run Web Prompter Backend, then Web Prompter Launch. Choose the text track. On a tablet, open the REAPER HTTP address shown in Control/OSC/web on the same LAN.
  • Configure roles, actors, solo/mute or dim filters, UI Scale and line/page auto-scroll. Actor colors take priority; project colors can be ignored.
  • Segments can come from markers/video or manual definitions. If cues are missing, check segmentation and the whole-project display mode. Click-to-jump respects pre-roll and playback/recording guards.

Limitations and data

  • There is no direct source-text editing in the monitor and no built-in SRT/ASS importer. Prepare text in REAPER; the separate Media Import extension can create text items.
  • The backend writes text to reaper_www_root/subtitles.json. Global settings use settings.json; a saved project’s role map is <project>-roles.json beside the project. These working data should not be uploaded to GitHub Pages.
  • REAPER serves the working HTTP interface on your computer. This GitHub Pages portal provides documentation and does not connect to your REAPER instance. Keep the working interface on a trusted network.
  • The README gives no exact minimum REAPER/OS versions. Its old Windows 7/8 FAQ does not establish current WebView2 support on those systems.

If the monitor is empty

  • Check the backend, selected track and nonempty P_NOTES. Then check the HTTP csurf entry, prompter.html and port.
  • Save the project if its name fails to update; restart Launch for display issues. If clicks do not move the cursor, check Jump settings, pre-roll and transport guards.

Sources and updates

  • The source consists of Lua scripts, a static web UI and a Python installer. main.yaml builds release installers.
  • Preserve settings and project role maps before replacing Scripts, reaper_www_root and optional UserPlugins, or use the installer. Restart REAPER.
