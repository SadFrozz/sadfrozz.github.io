Reaper Media Import

Extended codec support, HDR video without conversion, and subtitle import onto a track as text.

Windows x64macOS 11+
Downloads ↓Source code ↗Changelog ↗
v1.3.0

What it does

  • A native REAPER extension for raw Dolby/DTS/MLP audio, streaming TrueHD+AC3, ASS/SSA/SRT/WebVTT subtitles and audio stream selection in multitrack MKV/MP4. Audio and video stay in the original container.
  • Version 1.3.0 adds hardware HDR tone mapping and a dedicated Media Import preferences page.

Requirements

  • REAPER 7.66+; FFmpeg 9.x requires REAPER 7.80+. Windows x64 or macOS 11+ (Universal 2: Intel and Apple Silicon).
  • A full shared FFmpeg 5.x–9.x build, with libavcodec/libavformat major ABI 59–63 and their dependencies. A standalone ffmpeg executable or a static archive does not supply the required shared libraries.

Installation

  1. Download the v1.3.0 archive for your OS below. SHA256SUMS.txt is available in the same release.
  2. In REAPER, open Options → Show REAPER resource path in explorer/finder, then close REAPER.
  3. Copy reaper_frzz_media_import.dll (Windows) or reaper_frzz_media_import.dylib (macOS) into the resource directory’s UserPlugins folder.
  4. Place matching shared FFmpeg libraries there as well: DLLs from a full shared build’s bin folder on Windows; compatible dylib files or links on macOS.
  5. Prioritize ffmpeg_hw under Preferences → Media → Video/Import/Misc and restart REAPER. Refer to the tagged README for FFmpeg setup commands and the macOS quarantine procedure.

Usage

  • Drop supported raw audio into the project or use normal media insertion. For .thd+ac3, the TrueHD stream is read without a temporary media file.
  • Insert an MKV/MP4 containing multiple audio streams and choose by language, title, codec and channels. Item → Audio track and the item context menu switch the active take’s stream. The selection is saved; Undo/Redo each take one step.
  • ASS/SSA/SRT/VTT become timed text items relative to the insertion position. UTF-8 and UTF-16 LE/BE with a BOM are supported. These items can prepare text for Web Prompter.
  • Preferences → Plug-ins → Media Import controls stream selection, HDR/Dolby Vision → SDR, HEVC fixes and seek frame skipping. Apply takes effect without restarting. Hardware HDR is available on Windows x64 and Intel Mac; Windows caches shaders in UserPlugins/Shaders.
  • Dolby Vision Profile 5 uses RPU, Profile 7 uses the base layer with RPU, and Profile 8.1 uses the HDR10 base layer.

Limitations

  • Compatibility with AC-4 and uncommon DTS-HD/ES/X/UHD variants is unconfirmed. Import support depends on the codec inside the file.
  • Height channels are omitted: 7.1.2 becomes 7.1, retaining main channels and LFE. This is not an Atmos object renderer.
  • Subtitle styling, placement and visual layer order do not become text-item formatting. SRT supports up to 10 original text lines per item.
  • Native audio-track selection depends on the REAPER build. After updating REAPER, check that the Audio track menu opens for an MKV or MP4 with multiple audio streams.
  • Hardware HDR tone mapping is available on Windows x64 and Intel Mac. The Intel Arc/QSV mode is experimental and untested on physical Arc hardware.

Troubleshooting

  • Check the resource path of the active REAPER installation, especially for portable installs. REAPER, extension and FFmpeg architectures must match.
  • Check the shared libraries and video decoder priority. Report REAPER, extension and FFmpeg versions and a reproducible format. Avoid attaching personal media unnecessarily.

Build from source

  • Use v1.3.0 to reproduce the release. Requirements include CMake 3.24+, submodules and Visual Studio 2022/Windows SDK or Xcode Command Line Tools.
  • Windows commands after cloning with --recurse-submodules follow below. macOS uses macos-universal and mac-universal-release presets. Hardware HDR is enabled by default on Windows x64 and Intel Mac, controlled by FRZZ_ENABLE_WINDOWS_HDR and FRZZ_ENABLE_MACOS_HDR. Tone-mapping curves and RPU handling adapted from libplacebo compile into the extension, with native D3D11/OpenGL shaders.
cmake --preset vs2022-x64
cmake --build --preset release
ctest --preset release
