REAPER WebView

A browser inside REAPER: dockable windows, independent instances and a ReaScript API.

Windows x64macOS Universal
Downloads ↓Source code ↗
v0.2.0 · Pre-releaseReviewed 24 Nov 2026

Embedded browser

  • Uses WebView2 on Windows and WKWebView on macOS. Includes independent windows, find-in-page, context menus, window placement and REAPER shortcut forwarding.
  • Latest publication: v0.2.0, 11 September 2026, marked Pre-release. Main matches the tag at this snapshot.

Requirements

  • REAPER on Windows x64 or macOS with the appropriate Universal library. Windows requires Microsoft Edge WebView2 Runtime; the build SDK does not replace the installed Runtime.
  • Network pages require network access. WKWebView uses the macOS system engine. The README does not define an exact minimum REAPER version; none is invented here.

Installation

  1. Open v0.2.0 and download your platform archive. /releases/latest can skip pre-releases; use the exact link below.
  2. Open Options → Show REAPER resource path, then close REAPER.
  3. Extract the archive into UserPlugins: reaper_webview.dll on Windows or reaper_webview.dylib on macOS. Keep WebView2Loader.dll beside the extension if included.
  4. Restart REAPER. Use the Release binary for normal work; debug builds are for diagnostics.

Usage and API

  • Create a Lua ReaScript and run the example below to open a named browser in the Docker.
  • InstanceId defaults to wv_default; random generates sequential wv_N IDs; custom names must start with wv_. Other names resolve to wv_default.
  • ShowPanel accepts hide, docker or always. SetTitle sets a custom title; BasicCtxMenu enables the minimal menu. URL "0" applies options without navigating.
  • Preferences → Plug-ins → WebView controls the home page, shortcut forwarding and window restoration. Ctrl+F/Cmd+F opens find.
reaper.WEBVIEW_Navigate("https://www.reaper.fm/",
  '{"InstanceId":"wv_reference","SetTitle":"Reference","ShowPanel":"docker"}')

Limitations

  • This is a pre-release. The current build does not support Linux.
  • Routing browser audio into REAPER/ReaRoute is a roadmap item, not a delivered feature.
  • macOS find highlights are capped at 5000 with fallback counting. Website behavior depends on the system web engine.
  • Do not infer legacy Windows support from another project’s old FAQ; check the available WebView2 Runtime’s OS requirements.

If the window does not open

  • Check that reaper.WEBVIEW_Navigate exists, the correct resource folder is used, the architecture matches and the Windows Runtime is installed.
  • Use distinct wv_* IDs or random for multiple windows. Report OS, REAPER version, a URL without private parameters and a minimal Lua example.

Building

  • Clone with --recurse-submodules. Requires CMake 3.20+, a C++ toolchain, REAPER SDK, WDL and WIL on Windows. CMake downloads the WebView2 SDK from NuGet.
  • Targets: reaper_webview and reaper_webview_debug. macOS requires the Xcode toolchain. See README for full platform commands.
cmake -S . -B build
cmake --build build --config Release --target reaper_webview
